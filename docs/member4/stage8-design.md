# Stage 8 - MedCore DB-SOC Incident Investigation

## Objective

Participants act as Database Security Analysts and investigate multiple database alerts.

## Learning Outcomes

- Alert triage
- Database activity analysis
- Service account review
- Maintenance validation
- Network event correlation
- Insider threat detection

## Incident Summary

Five alerts are provided.

Four alerts represent legitimate business or operational activity.

One alert represents an actual database security incident involving:

- Expired account
- Unauthorized source
- Sensitive data export

## Flag Format

PULSE{ALERTID_ACCOUNT_OBJECT_ROWS}
