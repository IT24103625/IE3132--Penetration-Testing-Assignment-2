# IE3132 – Penetration Testing Assignment 2

## OPERATION PULSELOCK

**Real-World Smart Hospital and Research Database Breach Investigation CTF**

## Project Overview

This repository contains the implementation and documentation for the **IE3132 – Penetration Testing Assignment 2**.

**OPERATION PULSELOCK** is a controlled Capture The Flag (CTF) environment designed around a realistic smart hospital and research database breach investigation scenario. The project focuses on practical penetration-testing concepts, vulnerability identification, exploitation, investigation, testing, and security analysis.

## Project Objectives

* Develop a structured CTF-based penetration-testing environment.
* Implement the assigned penetration-testing scenarios and challenges.
* Apply practical vulnerability identification and exploitation techniques.
* Test and validate the implemented challenges.
* Document the platform architecture, implementation, testing, and results.
