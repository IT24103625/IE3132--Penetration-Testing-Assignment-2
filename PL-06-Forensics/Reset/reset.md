# PL-06 Reset and Recovery

## Reset Method
PL-06 uses immutable downloadable forensic evidence.

## Procedure
1. Delete the participant's modified local evidence files.
2. Download the original PL-06-Evidence.zip from CTFd.
3. Verify the SHA-256 checksum of the downloaded ZIP.
4. Extract the original evidence files.
5. Restart the forensic timeline investigation.

## Recovery
No server-side reset is required because participants analyze local copies of the evidence. The original evidence package remains unchanged on CTFd.
