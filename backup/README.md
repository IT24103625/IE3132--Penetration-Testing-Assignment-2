# Operation PulseLock Backup Package

This folder contains backup resources for the Operation PulseLock CTF platform.

Contents:

- ctfd_backup.sql
- OperationPulseLock-CTFd-Backup.zip
- BACKUP_AND_RESTORE_GUIDE.md

Purpose:

These files allow the CTF platform and challenge data to be restored in case of system failure, accidental deletion, or migration to another machine.
